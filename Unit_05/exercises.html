Exercise 01

色彩角色卡：5 個角色配對

20 分鐘個人Figma範本檔 · 區塊 ①

挑一個來源色（品牌色），推出至少 5 組色彩角色配對，做成講義第 1 節那種色票卡的樣子。20 分鐘內手動微調 5 組配對的深淺並不夠時間，用色彩生成工具先產出一套色階，再對應到角色，把時間花在檢查與對比度實測上。

步驟

  1. 選一個來源色（Hex 色碼隨你挑，不要太飽和也不要太灰）。
  2. 用 Material Theme Builder（Figma 外掛，安裝與操作見 Unit 09 外掛操作指南）貼入來源色，產生一整套色階；沒裝外掛的話，搜尋「Material theme builder」網頁版直接產生。
  3. 從產生的色階裡對應出 Primary／On Primary、Primary Container／On Primary Container、Secondary／On Secondary、Surface／On Surface、Error／On Error 共 5 組配對，把色碼複製回 Figma。
  4. 每組畫成一張色票卡：色塊 + 色塊上的文字（用該組的 On 色）+ 角色名稱標籤。
  5. 用線上對比度檢查工具（搜尋「contrast checker」），逐組實測背景色跟 On 色的對比度，記在角色名稱旁邊。
常卡住：只挑了背景色就結束，沒有另外決定 On 色，結果文字色隨便選一個深色——一定要兩個顏色一起決定，並實測對比度。
交件：5 張色票卡，每張都標角色名稱、色碼、對比度數字，且對比度都 ≥ 4.5:1。

Exercise 02

Type Scale：套進一段真的內容

20 分鐘個人Figma範本檔 · 區塊 ②

把 Unit 03 卡片的標題、副標，換成套用正確 Type Scale 角色的版本，並補上頁面標題與一段內文。

步驟

  1. 幫卡片加一個頁面標題（例如「本週推薦」），套用 Headline 角色的字級。
  2. 卡片標題（例如「城市小旅行」）套用 Title 角色的字級。
  3. 加一段兩三句的行程說明文字，套用 Body 角色的字級。
  4. 卡片上的按鈕文字套用 Label 角色的字級。
  5. 檢查四層文字排在一起，用途是不是一眼分得出來（頁面標題、卡片標題、內文、按鈕標籤各自的角色清楚，不是只看字級大小——同一角色的字級、行高、字重、字距要一起對齊，不同角色不一定要差很多字級）。
交件：同一個畫面裡出現 Headline／Title／Body／Label 四種角色的文字，字級順序看得出層級。

Exercise 03

Icon 對齊：跟文字基準線對齊

20 分鐘個人Figma範本檔 · 區塊 ③

在卡片上加一個小圖示（例如地點或日期 Icon），跟旁邊的文字對齊。

步驟

  1. 畫或找一個簡單的 Icon（用形狀工具拼一個幾何圖案即可，不用畫得很精緻），做成 24dp × 24dp。
  2. 放在卡片的副標文字旁邊（例如「📍 台北」的圖示位置）。
  3. 先不調整位置，觀察 Icon 中心跟文字看起來是否對齊。
  4. 把 Icon 往下移動大約文字字級的 11.5%（例如文字是 14px，往下移約 1.6px），比較移動前後的差異。
  5. 再做一個 40dp 的 Icon，放在 Headline 級的標題旁邊，重複同樣的對齊調整。
交件：兩組 Icon＋文字（24dp 配 Body／Label 級文字，40dp 配 Headline 級文字），都做過基準線位移。

Exercise 04

按鈕 5 狀態 Variants

20 分鐘個人Figma範本檔 · 區塊 ④

把 Unit 03 做的按鈕 Component，擴充成有 5 個狀態的 Component Set。

步驟

  1. 複製 4 份按鈕 Component，分別調整成 Hover（顏色加深）、Pressed（顏色加深，可搭配輕微縮小，例如 98% 左右）、Focus（加一圈外框，用 Secondary 或其他強調色）、Disabled（降低飽和度與對比，但文字仍要維持可讀）。
  2. 連同原本的 Enabled，五個都各自執行 Create component。
  3. 全選五個，右側面板點 Combine as variants，屬性改名成 State，數值改成 Enabled／Hover／Pressed／Focus／Disabled。
  4. 切到 Prototype 分頁，把 Enabled 對 Hover 接一條 While hovering 的連接，體驗一次狀態切換。
常卡住：Focus 只改了顏色沒加外框——去看講義第 8 節，Focus 一定要有外框，不能只靠顏色分辨。Disabled 對比降太多會整個看不清楚，記得核對文字是不是還讀得出來，不是只看有沒有變灰。
交件：一個 Button Component Set，含 State=Enabled／Hover／Pressed／Focus／Disabled 五個 Variant，Focus 有外框、Disabled 文字仍可讀。
回家作業

擴充成一頁風格指南

預估 2 小時。把課堂做的色彩角色卡、Type Scale、Icon、按鈕，收進一頁完整的風格指南，Unit 06 開始會直接拿來套用。

Homework

一頁風格指南 + 套用在一個真實畫面上

約 2 小時個人Figma
  1. 把 5 組「背景／On」色彩角色配對擴充到 7 組以上。補上 Secondary Container、Surface Variant／On Surface Variant 至少兩組，每組都要有對應的 On 色並實測對比度。另外加上 Outline 一項——它是邊框與分隔線用的功能角色，沒有配對的 On 色，不用測文字對比，但要整理進同一份色票規範裡並註明用途。
  2. 整理成一份 Type Scale 對照表。在課堂四個角色（Headline／Title／Body／Label）之外，補上 Display，五組角色各挑一個級別（Large／Medium／Small 擇一），列出字級、行高、字重、字距、用途，排成表格或卡片。
  3. 把風格指南套用在一個真實畫面上。挑一個簡單畫面（例如列表頁或詳細頁），全部文字用 Type Scale 角色、全部顏色用色彩角色、Icon 沿用課堂那個做的對齊方式、按鈕用今天做的 Component，不要留任何「隨手選的」顏色或字級。

交件前自己跑一次這個檢查

  • 畫面上有沒有任何文字的字級，不是套用 Type Scale 角色、而是隨手打的數字？
  • 畫面上有沒有任何顏色，不是套用色彩角色、而是隨手選的？
  • 按鈕的 Disabled 狀態，文字還讀得出來嗎？
  • 色票規範裡每一組 On 色，對比度都實測過、達到 4.5:1 了嗎？

AI 使用界線

可以不可以
色彩檢查把角色配對的色碼貼給 AI，請它指出缺漏的角色或明顯不足的配對讓 AI 幫你決定品牌色或整體色彩風格
字級檢查讓 AI 檢查同用途文字的字級是否一致讓 AI 幫你決定要用哪個字級角色
按鈕檢查把 Variant 清單貼給 AI，讓它抓出缺漏的狀態讓 AI 生成整組按鈕的視覺設計

界線的邏輯：AI 可以幫你檢查與排查問題，不能幫你做設計判斷。三段提示詞在講義第 12 節。

交件方式：一份 Figma 連結，權限設為可檢視。下次上課抽點分享色彩方案怎麼選的。
