## 背景

這個 repo 原本是「資展國際 UI/UX 網頁設計師養成班」的教材（2026/06/26–08/19，週間班），12 個 Unit 資料夾、`index.html`、每個單元的 README 都是照資展的日期與課程順序寫的。課程改到國立清華大學開班（9/16–12/9，每週三 13:20–16:20，共 12 次），且清大這邊已有一份官方 12 堂課主題大綱，跟現有 Unit 內容的順序、顆粒度都不一樣（例如清大主表把訪談／競品分析／旅程地圖三堂課壓成一堂，也多了「Figma 基本操作」「期中報告」「No-Code 實作」這幾個現有教材完全沒有對應內容的主題）。

## 功能說明

1. **課綱文件**：新增 `清華大學課程大綱.md`（12 列主表日期對齊 9/16–12/9），舊的資展課綱與最原始的 Figma 導向課綱合併進 `舊版課綱備查.md` 保留歷史備查，原始檔案刪除。
2. **Unit 資料夾重新編號**：依清大 12 場課綱的順序與主題，把現有 12 個 Unit 資料夾重新編號、部分合併、部分留白待補（對照表見變更紀錄）。
3. **入口文件同步**：`index.html`、根目錄 `README.md`、`CLAUDE.md` 的課程名稱、日期、單元清單、連結全部改成清大版本。
4. **教材整合**：對「只是結構合併／可以直接沿用」的 4 個單元（Unit_02、04、08、09）用 `unit-materials` skill 做初版整合或改寫，並跑 Codex 內容複審修正確定錯誤。
5. **skill 補強**：`unit-materials` skill 的語氣規範新增「不要太強硬」一節（收斂命令式開頭與武斷因果句，改用業界工作者交接工作的專業講法）。
6. **行事曆**：12 場上課日期建立到用戶的 Google Calendar（不屬於 repo 內容，僅記錄於此供追溯）。
