Figma 基本操作

Unit 01–02 把使用者、問題、旅程想清楚了，這堂課換工具：把想法變成一份能在 Figma 裡打開、點得動的檔案。四件事疊起來講——形狀與圖層是最基本的畫面素材，Auto Layout 讓版面跟著內容自動調整，Component 與 Variants 讓重複的元素只需要維護一份，Prototype 把靜態畫面接成可以點擊測試的原型。這四件事不是各自獨立的功能，是畫 Wireframe、建立設計元件、做互動原型的地基，Unit 04 開始會一直用到。

01

形狀工具與圖層基礎

Figma 提供六種基本形狀工具，是大多數畫面裡「非文字」圖層的來源。操作方式一致：從工具列選工具，在畫布上點擊拖曳，拖曳時畫面會即時顯示尺寸。

工具快捷鍵說明
RectangleR矩形或正方形；有專屬圓角控制點，可直接拖曳調整圓角
LineL任意方向的直線；可在右側調描邊顏色、粗細、虛線長度與間距
ArrowShift + L單向或雙向箭頭
EllipseO橢圓或正圓
Polygon—預設三角形，邊數在右側 Appearance 區塊的 Count 欄位調整
Star—預設五角星，角數同樣用 Count 調整

拖曳時按住 Shift 可以畫出正方形、正圓、正多邊形；按住 Option/Alt 會從中心點開始畫圖形或縮放，兩個修飾鍵可以同時按。圖片、GIF、影片不是獨立的圖層類型，而是「Fill（填色）」的一種——只要圖層支援 fill 屬性，拖放或貼上就能把影像加進去。

圖層順序決定畫布上的堆疊

一份設計通常是形狀、文字與其他圖層的組合，這些圖層可以在畫布上互相堆疊，同時仍然可以被個別編輯。圖層順序（layer order）決定畫布上的堆疊關係：圖層面板裡排在上面的圖層，在畫布上會蓋在排在下面的圖層上方。

每個圖層都有對應屬性：位置（X/Y 座標）、尺寸（寬高），以及外觀相關的顏色、描邊、效果（如陰影、模糊），這些屬性顯示在右側面板，內容依圖層類型而不同。

02

Frame：接下來三個功能的地基

除了形狀與文字，Figma 的圖層還有 Frame、Component、Instance 等類型。其中 Frame（框架）是最基礎的容器，用來組織物件與畫面，有明確的寬高與屬性，內建裝置尺寸預設（如 iPhone、Apple Watch）與常用素材尺寸，可以快速套用。

類型說明
Frame最基礎的容器；是 Component、Auto Layout、Prototype 這些功能的基礎
Text用 Text 工具建立，內建數百款免費 Google 字體，也可加自訂字體
Shape矩形、橢圓、多邊形等；Pen 工具可畫線條與自訂插畫
Image以 fill（填色）的形式存在，不是獨立圖層類型
記住這個順序：Auto Layout、Component、Prototype 這三個接下來要講的功能，都是以 Frame 為基礎建立的。一般圖層要用這些功能，Figma 通常會先幫你包一層 Frame。

03

Auto Layout 是什麼、為什麼用

Auto Layout 讓 Frame 裡的元素「根據方向、間距、留白、對齊等屬性自動排列」——內容一旦變動，版面會自動跟著調整，不用手動重新排位置。

手動排版時，內容一變動就要重新調整每個元素的位置；按鈕的文字變長、清單多了一筆、要支援多種螢幕尺寸，這些狀況手動排版都要重新對齊一次。Auto Layout 設定好方向、間距、留白、縮放行為後，內容變動時所有元素會依照這些規則自動同步調整位置。

適合使用 Auto Layout 的情境：文字長度會變的按鈕、項目數量會增減的清單、儀表板，以及要支援多種螢幕尺寸的網頁。

04

加上 Auto Layout：步驟與四個屬性

三種觸發方式

  1. 選取一個或多個圖層。
  2. 按快捷鍵 Shift + A，或點右側面板 Auto Layout 旁的加號，或右鍵選單選 Add auto layout。
  3. Auto Layout 只作用在 Frame 上——如果選取的是一般圖層（不是 Frame），Figma 會自動在外面包一層 Auto Layout Frame。
  4. 如果選取的是 Frame 或 Main Component，可以直接選擇 Flow 類型：Vertical（沿 y 軸）、Horizontal（沿 x 軸，可選是否換行）、Grid（用欄與列排成網格）。

面對複雜版面，Mac 可以用 Control + Shift + A、Windows 用 Control + Alt + Shift + A，讓 Figma 自動判斷合適的 Auto Layout 結構，之後再手動微調；要移除的話，點 Freeform，或按 Option/Alt + Shift + A，會還原成一般 Frame。

四個關鍵屬性

屬性在調什麼
PaddingFrame 邊界與內容之間的空白
Gap物件與物件之間的距離，可以是固定值，也可以用 Between／Around／Evenly 等自動間距模式
Alignment決定物件在 Frame 裡的對齊方式
ResizingHug contents（依內容縮到最小）／Fill container（撐滿父層可用空間）／Fixed（固定尺寸不變），也可設定 min/max 限制範圍
個別物件可以開啟 Ignore auto layout，讓它跳出自動排列邏輯、改用絕對定位——例如浮動在角落的通知紅點。

05

Component 與 Instance

Main Component（主元件）定義這個元素的所有屬性；Instance（實體）是主元件的副本，可以在設計裡重複使用。修改 Instance 時可以調整文字、填色、描邊、效果等屬性，讓它符合當下的使用情境，或用來嘗試不同的設計變化。

不能修改 Instance 的底層結構——不能覆寫元件內圖層的堆疊順序（z-index），也不能移動元件內圖層的位置。

Push overrides to main component：可以把對 Instance 做的修改「推回」主元件，這樣同一個主元件底下的其他 Instance 也會一併更新。但這個功能只在主元件與 Instance 位於同一個檔案時才能使用。

06

Variants 與 Component Set

Variant（變體）是同一個元件的不同版本，彼此之間有可預期的差異（例如按鈕的大小、狀態）。多個 Variant 會被收進一個 Component Set（元件集）容器，方便管理與尋找。Variant 用「屬性（Property）」與「數值（Value）」定義差異：屬性代表可變動的面向（例如 Size、State），數值是每個屬性底下的具體選項，每個 Variant 必須是屬性數值的唯一組合。

把多個 Component 合併成 Variants

  1. 選取多個 Component。
  2. 在右側面板點 Combine as variants。
  3. Figma 會把它們整合進同一個 Component Set。
  4. Figma 預設會把屬性命名成 Variant、Property 2、Property 3 等通用名稱，要自己重新命名成有意義的名稱（例如 Type、Size、State）。

命名慣例範例：Button/Primary/Large/Default/False，代表 Component Set 名稱是 Button，底下有 Type（Primary）、Size（Large）、State（Default）、Icon（False）等屬性。這種命名法讓團隊可以透過同一個資產、切換不同屬性組合，取得需要的按鈕版本。

建議用獨立、命名清楚的屬性控制單一面向的差異，而不是用一個「Style」屬性同時控制多個變化——不要用一個屬性值「Primary Large」，而是拆成 Type=Primary、Size=Large 兩個獨立屬性，使用者才能自由混搭組合。

07

Prototype 基礎：Flow 與分頁切換

Prototype（原型）讓設計者「建立互動流程，模擬使用者可能如何跟設計互動」——在真正開發之前，就能預覽互動、分享想法、蒐集回饋、測試體驗。

Figma 檔案裡有 Design 與 Prototype 兩個分頁，可用快捷鍵 Shift + E 快速切換：Design 分頁做視覺設計，Prototype 分頁設定互動。

Flow（流程）指的是「同一個頁面裡，Frame 與連接線組成的網絡」；一個檔案可以有多個 Flow，對應不同的使用者旅程（例如註冊流程、購物車流程、結帳流程各自是一條 Flow）。每條 Flow 需要一個起點，可以手動指定，或者加上第一條連接線時 Figma 會自動建立。

端到端流程

  1. 在畫面之間建立連接（選一個熱區／物件，拖曳到目標畫面）。
  2. 在 Prototype 分頁設定互動（Trigger／Action）與動畫效果。
  3. 設定 Prototype 的整體設定（裝置外框、背景色、起始畫面）。
  4. 用 Preview 預覽並測試互動流程。
  5. 分享整個 Prototype，或分享特定 Flow 的起點連結給他人測試。

08

建立連接：Trigger、Action、Destination

建立連接的步驟

  1. 切到右側面板的 Prototype 分頁。
  2. 選取要當作起點的物件（熱區）。
  3. 拖曳物件邊緣出現的「＋」到目標 Frame，或在 Interactions 區塊點 Add。
  4. 在互動細節面板設定 Trigger／Action／Destination。
  5. 關掉面板即完成這條連接。也可以一次選多個物件，把「＋」拖到同一個目標 Frame，批次建立相同的連接。
要件意思
Trigger（觸發條件）引發互動的事件，例如 On click（點擊）、While hovering（滑鼠停留）、After delay（延遲後）、When video ends（影片播放結束）。同一個物件可以同時有多個 Key/Gamepad、On drag 或 When video hits 類型的觸發條件
Action（動作）觸發後發生的事，例如跳到另一個 Frame、開啟 Overlay（疊加視窗）、播放影片
Destination（目的地）連接線的終點，大多數情況下必須是「最上層的 Frame」

09

動畫與轉場設定

互動細節面板裡可以設定：

  • 動畫類型：Push（推移）、Slide（滑入）、Dissolve（淡入淡出）等。
  • 方向：左／右／上／下（依動畫類型而定）。
  • Smart Animate：自動對「兩個畫面裡同名的圖層」做轉場動畫——例如按鈕從左邊移到右邊時，會自動產生移動動畫。
  • Easing／Spring：控制轉場的加速曲線。
  • Duration（時長）：可設定 1–10,000 毫秒。
設定完成後可以直接在面板裡預覽動畫效果，再決定是否套用。Smart Animate 要生效，兩個畫面裡對應的圖層名稱要一模一樣——這是課堂練習 Exercise 04 最容易卡住的地方。

10

課堂練習與回家作業

課堂練習用 70 分鐘，把今天四個功能疊在同一張卡片上做出來：形狀與圖層 → Auto Layout → Component 與 Variants → Prototype 連接。完整步驟、時間分配與交件標準在練習頁。

回家作業把課堂的卡片擴充成一頁小型元件庫，並串成至少 3 個畫面的 Prototype Flow，細節在練習頁的回家作業。
