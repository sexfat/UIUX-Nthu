從一張卡片到可以點的 Prototype

四個階段接著做，中間不停。做不完的部分列進回家作業。

Exercise 01

形狀與圖層：畫出一張卡片

15 分鐘個人Figma範本檔 · 區塊 ①

目標是重現講義第 1 節那張旅遊卡片的圖層結構——不用畫得一模一樣，重點是練到「形狀＋圖層堆疊」。

步驟

  1. 按 R 畫一個矩形當作照片，填任意顏色，圓角調成 12px 左右。
  2. 按 O 畫一個小圓當頭像，疊在照片矩形的左下角——確認圖層面板裡頭像排在照片上面。
  3. 用 Text 工具加一行標題、一行副標，疊在照片下方或上方，確認文字圖層在最上層。
  4. 把照片圖層拖到圖層面板最上面，觀察畫面：頭像跟文字被蓋住了嗎？拖回原位。
交件：一張至少 4 個圖層（照片、頭像、標題、副標）疊出來的卡片，圖層順序正確（頭像與文字在照片上面）。

Exercise 02

Auto Layout：加上一排標籤

15 分鐘個人Figma範本檔 · 區塊 ②

在 Exercise 01 的卡片下方，加一排標籤（例如「親子」「三天兩夜」「秋季」），練習 Auto Layout 的 Gap 與 Hug。

步驟

  1. 先手動排 3 個標籤（各自是一個小 Frame + 文字，寬度先固定），把其中一個標籤的文字改長一點，觀察文字有沒有溢出固定寬度的標籤框——這就是講義第 3 節講的手動排版問題。
  2. 刪掉重來：每個標籤自己先變成 Auto Layout Frame（選取文字，按 Shift + A），Padding 上下 6px、左右 12px，Resizing 選 Hug contents——這一步不能省，不然文字變長時標籤本身不會跟著撐開。
  3. 再建一個外層 Frame，選取後按 Shift + A 加上 Auto Layout，Flow 選 Horizontal，Gap 設成 8px 左右，Resizing 也選 Hug contents。
  4. 把 3 個已經是 Auto Layout 的標籤依序拖進這個外層 Frame 裡，再把其中一個文字改長，觀察標籤會不會自動撐開、不重疊。
  5. 打開外層 Frame 的 Wrap，把 Frame 寬度縮小，確認標籤會自動換行。
常卡住：只對外層那排設定 Auto Layout 還不夠——如果每個標籤本身還是固定寬度的 Frame，文字變長只會在標籤內溢出，不會撐開標籤。每個標籤自己也要是 Auto Layout Frame，Resizing 設 Hug contents，外層的排列才會跟著正確撐開。Shift + A 完全沒反應時，改用右鍵選單的 Add auto layout 再檢查一次。
交件：一排用 Auto Layout 排出的標籤（外層跟每個標籤本身都是 Auto Layout Frame），文字變長時會自動撐開、不重疊，縮小寬度時會自動換行。

Exercise 03

Component：做一顆按鈕與 2 個 Variant

20 分鐘個人Figma範本檔 · 區塊 ③

做一顆「查看行程」按鈕，練習 Component 與 Variants，之後 Exercise 04 會直接用到它。

步驟

  1. 用 Auto Layout Frame 做一顆按鈕：Padding 上下 10px、左右 20px，裡面放一行文字「查看行程」，Fill 填藍色。
  2. 選取這個按鈕 Frame，右鍵選 Create component，變成 Main Component。
  3. 複製一份，把 Fill 改成淺色、文字改深色，當作第二種樣式（Secondary），一樣右鍵 Create component。
  4. 兩個 Component 都選取，右側面板點 Combine as variants。
  5. 把自動命名的屬性改成 Type，數值改成 Primary／Secondary——不要留著 Figma 預設的 Variant、Property 2 這種名字。
常卡住：Combine as variants 按了沒用，通常是選到的物件不是 Component（還是一般 Frame）——先確認兩個物件都各自執行過 Create component。
交件：一個 Button Component Set，含 Type=Primary 與 Type=Secondary 兩個 Variant，屬性命名清楚（不是預設的 Property 1、Property 2）。

Exercise 04

Prototype：接出一次點擊互動

20 分鐘個人Figma範本檔 · 區塊 ④

把 Exercise 01 的卡片、Exercise 03 的按鈕放進同一個 Frame，再複製一份當作「詳細頁」，接出一次可以點的互動。

步驟

  1. 建立一個手機尺寸的 Frame（用 Frame 預設裡的 iPhone 尺寸），命名為「列表頁」。打開右側的 Assets 面板，找到 Exercise 03 做的 Button 元件，把它拖進畫面裡——這樣拖進來的就是一個 Instance。把 Exercise 01 的卡片也放進來（直接複製圖層即可，卡片這裡先不用做成 Component）。
  2. 複製整個 Frame，改名為「詳細頁」，換掉一些內容（例如放大照片、加一段說明文字），讓兩個畫面看得出差異。
  3. 按 Shift + E 切到 Prototype 分頁。
  4. 選取列表頁裡的按鈕，拖曳右側出現的「＋」到詳細頁的 Frame 邊界上。
  5. 在互動細節面板確認 Trigger 是 On click，Action 是 Navigate to，Destination 是「詳細頁」這個最上層 Frame。動畫先選 Push，方向 Left。
  6. 點右上角 Preview，實際點一次按鈕，確認畫面真的切換過去。
常卡住：連接線拉不出去，通常是目標不是最上層 Frame（例如拖進了 Frame 裡面的某個圖層），或熱區選到的是文字圖層而不是外層可點的容器。
交件：Preview 模式下，點擊按鈕能從列表頁切換到詳細頁，且有 Push 動畫。
回家作業

把卡片擴充成一頁小型元件庫

預估 2 小時。把課堂做出來的卡片、按鈕、Prototype，擴充成 Unit 04 開始會用到的一份基礎素材。

Homework

2 個 Component、Auto Layout 卡片與 3 畫面 Prototype

約 2 小時個人Figma
  1. 再做 1 個 Component，跟課堂的按鈕湊成 2 個。挑一個卡片上會重複出現的元素（例如標籤、小圖示按鈕），至少要有 2 個 Variant，屬性命名要看得懂，不要留 Figma 預設名稱。
  2. 用 Auto Layout 重排整張卡片，同時保留頭像疊在照片上的效果。把照片、標題、副標三個「不重疊」的元素包進一個 Vertical Auto Layout Frame（Resizing 設 Hug contents），確認換一行更長的標題時卡片高度會自動跟著變。頭像維持疊在照片上——選取頭像圖層，在右側面板打開 Ignore auto layout，改用絕對定位疊在照片上，不要把它也塞進同一個 Auto Layout 排列裡（一般 Auto Layout 只會把子物件排開，不會讓它們重疊）。
  3. 串成至少 3 個畫面的 Prototype Flow。在課堂的列表頁、詳細頁之外，至少再加一個畫面（例如「編輯頁」或「確認頁」），並且要有返回的連接——從詳細頁能點回列表頁。
  4. （加分，非必要）把其中一個轉場換成 Smart Animate，確認兩個畫面裡要做動畫的圖層名稱完全一致，不然不會生效。

交件前自己跑一次這個檢查

  • 2 個 Component 的 Variant 屬性名稱，別人不看畫面猜得出差異嗎？
  • 卡片的 Auto Layout Frame，Resizing 是不是還留在 Fixed（改內容不會自動撐開）？
  • Prototype 裡有沒有進得去、出不來的畫面？

AI 使用界線

可以不可以
卡關排查把 Auto Layout 設定貼給 AI，請它指出可能的問題屬性讓 AI 決定版面該怎麼設計
命名檢查讓 AI 檢查 Variant 屬性命名是否清楚、有沒有語意重疊讓 AI 幫你決定要做哪些 Variant
連接檢查把 Prototype 連接清單貼給 AI，讓它抓出斷掉或進不去的畫面讓 AI 生成整個 Prototype 的畫面內容

界線的邏輯：AI 可以幫你檢查與排查問題，不能幫你做設計判斷。三段提示詞在講義第 11 節。

交件方式：一份 Figma 連結，權限設為可檢視。下次上課抽點分享卡在哪、怎麼解的。
